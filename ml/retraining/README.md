# TurSathi AI — Clean Retraining & Safe Deployment Guide

## 1. Overview
This workspace (`ml/retraining/`) contains the complete, reproducible training suite for the 5-class Pigeonpea (Tur / Arhar) disease classification model:
- **0: Healthy**
- **1: Leaf_Spot** (*Cercospora Leaf Spot*)
- **2: Leaf_webber** (*Maruca vitrata / Cydia critica*)
- **3: Sterilic_mosaic** (*Sterility Mosaic Disease / SMD*)
- **4: Wilt** (*Fusarium Wilt*)

## 3. How to Execute Training in Google Colab

### Step 1: Open Google Colab
1. Navigate to [Google Colab](https://colab.research.google.com/).
2. Click **Upload** and select `TurSathi_Clean_Retraining_and_OOD_Colab.ipynb` from your local folder:
   `c:\Users\admin\OneDrive\Documents\Desktop\TurSathi AI\ml\retraining\TurSathi_Clean_Retraining_and_OOD_Colab.ipynb`

### Step 2: Set Hardware Accelerator
1. In Google Colab menu, go to **Runtime** > **Change runtime type**.
2. Select **T4 GPU** (or any available GPU) and click **Save**.

### Step 3: Upload the Clean Dataset Archive
1. In Section 3 or Section 4 of the notebook, either:
   - **Option A (Fastest via Drive):** Copy `TurSathi_Pigeonpea_Clean_Dataset.zip` to your Google Drive root or a folder named `TurSathi/`, then run Section 3 to mount Drive.
   - **Option B (Direct Browser Upload):** Run Section 4 and use the upload widget to select `TurSathi_Pigeonpea_Clean_Dataset.zip`.

### Step 4: Run All Cells
1. Click **Runtime** > **Run all** (or press `Ctrl + F9`).
2. The notebook will:
   - Check GPU and dependencies.
   - Verify zero leakage across splits.
   - Train for 20 epochs with class-weighted loss to counter Wilt asymmetry.
   - Save the best validation accuracy checkpoint.
   - Evaluate against the untouched test split (producing the confusion matrix).
   - Calibrate per-class OOD cosine boundaries on validation data.
   - Test against the 41 real-world external OOD images.
   - Export the candidate model and OOD profile JSON.

## 4. Candidate Artifacts & Safe Deployment Protocol

### Output Files Generated by Colab Run:
- `tursathi_efficientnet_b0_candidate_<experiment_id>.pth` (~15.6 MB)
- `ood_feature_profile_<experiment_id>.json` (~170 KB)
- `training_report_<experiment_id>.json` (~3 KB)

### Safe Local Placement:
Download the generated files and place them into the candidate holding directory:
```
models/candidates/tursathi_efficientnet_b0_candidate_<experiment_id>.pth
models/candidates/ood_feature_profile_<experiment_id>.json
```

### Absolute Production Safety Rule:
**Never overwrite `models/best_pigeonpea_disease_final_efficientnet_b0.pth` automatically.**
Compare the candidate's test accuracy, genuine Wilt recall, and external OOD rejection rate with the baseline. Only promote the candidate to production after explicit review and approval.
